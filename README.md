# Financer

Minimal local-first personal finance PWA.

## Current scope

- Credit and debit transactions only.
- Category CRUD.
- Transaction CRUD.
- Optional simple or compound interest history per transaction.
- Profile default currency, using browser-supported ISO currencies with a fallback list.
- Static one-time license page for a $50 USD personal license.
- Local browser storage and offline-capable PWA shell.

## Run locally

```sh
npm run dev
```

Open `http://localhost:5173`.

## Check JavaScript

```sh
npm run check
```
